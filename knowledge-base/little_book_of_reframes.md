### How to use
1. During an objection, identify the *root* resistance.
2. Filter this table for the matching **trigger**.
3. Quote or paraphrase the **anchor text** to pivot the prospect’s thinking.

*(Full verbatim scripts live in the source TXT; this file stores a structured summary for rapid retrieval.)*
