## title: "Open‑Wallet Training – Overcoming *Financial* Objections" author: Mason Church tags: [sales, objections, finance]

> **Context:** Some prospects *can* pay but feel anxious; others literally cannot.  This module helps ChatGPT diagnose which bucket and coach the rep accordingly.

---

## 1.  Logistics vs. Uncertainty

| Bucket          | Symptom                                          | Response                                                           |
| --------------- | ------------------------------------------------ | ------------------------------------------------------------------ |
| **Logistics**   | Maxed cards, 540 credit, \$200 in the bank.      | *“Let’s brainstorm **how** to access funds…”*                      |
| **Uncertainty** | “I need to think,” but income & credit are fine. | *“Sounds like it’s not about money—what else is missing for you?”* |

---

## 2.  The Open‑Wallet Script

```text
1. Permission → “Can we zoom‑out on finances for a sec?”
2. Reality Check → “Roughly how much free cash or credit do you have access to today?”
3. Gap Surfacing → If ≥ investment → *uncertainty.*  If < investment → *logistics.*
4. Plan A (Logistics) → Funding resources list ↓
5. Plan B (Uncertainty) → Cost‑of‑inaction + micro‑commit.
```

---

## 3.  Funding Resources Cheat‑sheet

- **Low‑interest CC promo** (Amex Blue, Discover It…)
- **PayPal Credit / Stripe Capital**
- **CU Personal Loan** (3‑day approval)
- **401k Borrow** (no penalty, 5‑year term)
- **Family/Friend Bridge** (use Mason’s *Friendly Loan* template)

---

## 4.  Language Patterns & Micro‑Commitments

> *“Assuming money **wasn’t** the issue, are you sold this is the right fit?”*
>
> *“What would need to be true by next Friday for you to move forward?”*

---

## 5.  Red‑Flags → Politely Pass

| Signal                                       | Why we pass                          |
| -------------------------------------------- | ------------------------------------ |
| Will not share any financial truth.          | High probability of default / churn. |
| **Adds new CC just for call, hits decline.** | Desperation → buyer’s remorse.       |
| Blames economy / gov’t for everything.       | External locus of control.           |
